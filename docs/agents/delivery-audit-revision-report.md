### 2.3 **臂不变性**（关键结论）

**变化的 8 行，在 B / C / C′ 三臂上逐字节相同**（程序比对：`与基准相同: True`）。

**为什么这就够**：

1. 被改段落**不含 `不适用本清单`**（C′ 的剥离条件）⇒ **C′ 剥离行为不变**，没多删也没少删。
2. 该段在**处理臂（C′）与对照臂（B）中完全相同** ⇒ **处理与对照的差异未被触碰**
   ⇒ `Δ2′ = FTR(C′) − FTR(B)` 的对照结构**保持不变**；`Δ2 = FTR(C) − FTR(B)` 同理。
3. ⇒ **本改动只可能影响「各臂的绝对触发表面」，不可能影响「臂间差值」** ——
   三臂拿到的是同一段新文本。
