### 3.2 连跑对照轮（**同一个服务里不重启**，用来做配对归因；演示不采用这个口径）

| 次序 | 原图 | 打码后 |
|---|---|---|
| 第 1 次 | 20.31 s | 17.35 s |
| 第 2 次 | 20.31 → 13.37 s（同一张原图，同会话第二次） | 17.28 s |

## 4. 帽/衣色块命中的两种量法（结论不同，都要留）

### 4.1 逐框配对（IoU ≥ 0.56），跑完整管线

| 打码后 #↔打码前 # | IoU | confidence | 帽色块 | 衣色块 |
|---|---|---|---|---|
| #0 ↔ #0 | 0.67 | 0.000 → 0.000 | False → False | False → False |
| #1 ↔ #3 | 0.83 | 0.000 → 0.000 | False → False | False → False |
| #2 ↔ #2 | 0.74 | 0.000 → 0.000 | False → False | False → False |
| #3 ↔ #4 | 0.73 | 0.285 → **0.445** | True → True | True → True |
| #4 ↔ #1 | 0.70 | 0.463 → **0.752** | True → True | True → True |

**10 处「有没有」的判定全部一致**——打码没有翻转任何一条色块命中。

### 4.2 固定同一组人形框（用**打码前**检出的 6 个框，只换图）

| 框 | 打码前 帽/衣覆盖率 | 打码后 帽/衣覆盖率 |
|---|---|---|
| #1 | 0.4632 / 0.8116 | **0.3269** / 0.8107 |
| #4 | 0.2855 / 0.6305 | **0.1923** / 0.6315 |
| #5 | 0.1519 / 0.5758 | **未测到** / 0.3616 |

**头盔覆盖率三处全部下降**（头盔长在头上，正是被马赛克盖住的地方）；衣服基本不动（躯干没打码）。
**但 4.1 里跑完整管线时 confidence 反而上升**——因为**人形框本身也变了**（打码改了人形特征）。
**两个效应方向相反**：固定框 → 降；跑管线 → 由「框变 + 颜色变」共同决定。
