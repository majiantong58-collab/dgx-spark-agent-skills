# 分级路由与预算策略（Tier 0 / 1 / 2）

## 1. 层级定义

| tier | 载体 | 触发条件 | 成本 |
|---|---|---|---|
| **0** | 轻量检测器（ONNX Runtime GPU / TensorRT） | 高置信命中，单目标 | 本地，约 0 |
| **1** | 本地小 VLM（Qwen3-VL-4B INT4 级） | 置信度临界，或需一句话描述 | 本地，约 0 |
| **2** | StepFun Step Preview API（OpenAI 兼容端点） | 多目标冲突 / 需生成报告措辞 / 本地全部失败 | 按 token 计费 |

## 2. 升级判据（满足任一即升级，**不得越级**）

- `0.40 ≤ conf < 0.75` → Tier 0 → 1
- 需要自然语言描述而 Tier 0 只给标签 → Tier 0 → 1
- 同一帧出现 ≥ 3 个互相冲突的候选 → Tier 1 → 2
- 需要成文报告措辞 → `inspection-report` 走 Tier 2
- Tier 1 复核后 `conf` 仍 < 0.5 → 输出 `uncertain`，**不升 Tier 2**（避免为无结论付费）

## 3. 预算护栏（硬约束）

- **单帧图像默认不送 Tier 2**；仅"多目标冲突 / 报告生成"允许。
- 单次巡检任务 Tier 2 调用上限：**N 次**（配置项，默认保守）。
- 超预算 → 停止升级，返回 `partial: true` 与已完成结果，**不静默降级**。
- 未经用户明确授权，`Tier 2` 一律禁用 → 全部回落 Tier 0/1。

## 4. 失败与降级

| 场景 | 处置 |
|---|---|
| Tier 0 失败 | 升 Tier 1 |
| Tier 1 失败 | 升 Tier 2（若预算与授权允许），否则返回 `partial` |
| Tier 2 失败 | 回落 Tier 1 结果 + 标注 `degraded: true` |
| 同一子技能连续失败 2 次 | 停止重试，返回部分结果并上报 |

**降级方向永远朝本地**——本地兜底率是本项目的核心指标（目标 > 90%）。
