# evals — gauge-reading

## 用例字段

| 字段 | 说明 |
|---|---|
| `id` | 用例编号 |
| `type` | `positive` 应触发 / `negative` **正确答案是不调用本技能** / `positive_empty` 应触发但期望不确定结论 |
| `expect_trigger` | 本技能是否**应当被调用** |
| `expect_route` | 不该触发时，正确的去向；`[]` 表示谁都不调用 |
| `expect_value` | 期望读数：`{value, unit, range}`；`null` 表示期望「不确定」而非具体数值 |

## 三条轴的区分

1. **`negative`（4 条）** —— 正确答案是**根本不调用**。
2. **`positive`（5 条）** —— 应触发且应给出具体读数。
3. **`positive_empty`（1 条）** —— 应触发，但正确输出是 `uncertain` + 回问。
   `gauge-empty-001`（量程被反光遮住）考的是：**宁可不出数，也不编造量程**。

## 负向用例的理由

| id | 不该触发的原因 |
|---|---|
| `gauge-neg-001` | 画面里**没有表盘**。触发条件是「有仪表盘面」，不是「有图」 |
| `gauge-neg-002` | 无图像 + 趋势分析。本技能只做「单块表盘 → 一个数」 |
| `gauge-neg-003` | 设备铭牌是**文字 OCR**，不是仪表盘面读数——最典型的近似误触发陷阱 |
| `gauge-neg-004` | 纯数值计算，无图像 |

## 评分

| 指标 | 口径 |
|---|---|
| 触发准确率 | `expect_trigger` 判定正确率 |
| **负向误触发率 FTR** | 负例中被错误调用的占比 |
| 读数绝对误差 MAE | 指针表按满量程百分比归一后的平均绝对误差 |
| 单位正确率 | `unit` 与期望一致的占比 |
| **编造量程数** | 量程未知时仍给出数值的次数（应为 0）——安全边界硬指标 |
| 越限误判率 | 阈值未知时误报 `is_out_of_range` 的占比（应为 0） |
| 人工复核标记率 | `requires_human_review == true` 的占比（应恒为 100%） |
