# 仪表类型与读数方式

| gauge_type | 中文 | 读数方式 | 常见量程 | 默认单位 |
|---|---|---|---|---|
| `pressure` | 压力表 | 指针角度 → 线性映射 | 0–1.6 / 0–2.5 MPa | MPa |
| `temperature` | 温度表 | 指针或数字 | 0–100 / 0–600 ℃ | ℃ |
| `level` | 液位计 | 刻度线位置比例 | 0–100 % | % |
| `flow` | 流量计 | 数字串 | — | m³/h |
| `current` | 电流表 | 数字串 / 指针 | 0–100 A | A |
| `voltage` | 电压表 | 数字串 / 指针 | 0–450 V | V |
| `valve` | 阀门开度 | 圆盘刻度比例 | 0–100 % | % |

## 读数方式判别

1. **数字表** —— 有 LCD / LED 数字区：走数字串识别，需处理小数点与缺笔画。
2. **指针表** —— 有刻度盘 + 指针：**必须先有量程**，再算 `value = (θ - θ_min) / (θ_max - θ_min) * (R_max - R_min) + R_min`。
3. **双针表** —— 主针 + 记忆针：**必须报告是哪一根**，无法区分即 `uncertain`。
4. **多圈 / 带倍率表** —— 有 ×10 / ×100 标识：漏读倍率是最常见错误，读到倍率标识才允许出数。

## 硬规则

- 表盘被玻璃反光覆盖关键刻度 → 不出数，`uncertain: true`。
- 表盘倾斜 > 30° 且未做透视校正 → 不出数。
- 量程未知 → **回问用户**，不得假设。这是本技能最常见的失败模式。
