# 读数校验规则与置信度

## 1. 三重复核（`scripts/validate_reading.py` 实现依据）

| 校验 | 规则 | 不通过时 |
|---|---|---|
| 量程合理性 | `R_min ≤ value ≤ R_max` | 直接判为误读，`confidence = 0` |
| 指针-数字一致性 | 指针表若有数字标注，两者偏差 < 2% FS | 降置信至 0.5 以下 |
| 多帧一致性 | 同表连续帧读数极差 < 1% FS | 标 `uncertain`，取中位数 |

## 2. 置信度映射

| 条件 | confidence |
|---|---|
| 表盘完整、无反光、量程已知、三重校验全过 | ≥ 0.85 → 采纳 |
| 轻微反光 / 轻微倾斜但校验通过 | 0.5 – 0.85 → 升 Tier 1 复核 |
| 遮挡、强反光、量程未知、校验不通过 | < 0.5 → 输出 `uncertain` |

## 3. 越限判定

`is_out_of_range` 只在**同时**满足以下条件时为 `true`：

1. 量程与阈值已知（阈值由用户或台账给出，**不得自定义**）
2. `confidence ≥ 0.85`
3. 非 `uncertain`

其余情况一律 `null`，并写 `note: "阈值未知，未判定"`。

## 4. 恒真约束

- `requires_human_review` 恒为 `true`——仪表读数**永远**不直接触发停机或联锁。
- 单位未知时输出 `unit: "unknown"`，**不得**按表盘外观猜单位。
