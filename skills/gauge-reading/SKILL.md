# 仪表读数识别（Gauge Reading）

只做一件事：**把一块表盘读成一个带单位的数**。不判隐患、不做趋势、不写报告。

## Purpose

读取工业仪表盘面的数值与状态，覆盖压力表、温度表、液位计、电流/电压表、阀门开度五类表计。

## 前置问题（缺一不可，禁止猜测）

1. **表的类型与量程？** 量程未知 → **必须问**，不得凭指针角度反推量程。
2. **单位？** MPa / bar / ℃ / m³ / A。未知则输出 `unit: "unknown"` 并降置信。
3. **单表还是多表？** 多表须提供表位编号，否则读数无法归属，拒绝出结果。
4. **读数用途？** 抄表记录 vs 越限告警——决定是否需要 `is_out_of_range` 字段。

## 主流程

1. **输入校验** — 表盘是否完整入画、是否反光 / 模糊 / 被遮挡 / 倾斜过度。
2. **安全边界（前置，不是最后一步）**
   - 有遮挡、强反光、指针模糊时**禁止给出确定读数** → 必须带 `uncertain: true`。
   - **禁止编造量程与单位**；未知即 `unknown`，宁可不出数。
   - 读数**不得直接触发停机 / 联锁 / 报警处置**，输出恒带 `requires_human_review: true`。
   - 未获授权不得调用云端模型。
3. **定位表盘**（`scripts/read_gauge.py`：表盘检测 → 指针区域 / 数字区域分割）。
4. **读数**
   - 数字表 → 数字串识别。
   - 指针表 → 指针角度 → **已知量程**线性映射；量程未知即中止并回问。
5. **校验**（`scripts/validate_reading.py`）：量程合理性、指针与数字一致性、多帧一致性。
6. **分级** — `conf ≥ 0.85` 采纳；`0.5 ≤ conf < 0.85` 升 Tier 1 复核；`< 0.5` 输出 `uncertain`。
7. **返回结构化结果**并交回编排层；**不做趋势分析、不写报告**。

## 输出契约

```json
[{"gauge_id": "P-101", "gauge_type": "pressure", "value": 0.62, "unit": "MPa",
  "range": [0, 1.6], "confidence": 0.93, "tier": 1, "uncertain": false,
  "is_out_of_range": false, "requires_human_review": true}]
```

## 负向边界（何时本技能不该被调用）

- 图里是人员、通道、设备渗漏、明火 → 不调用，交 `safety-hazard-detection`。
- 只有一段表计历史数字 / CSV，没有图像 → 不调用。
- 问"这台泵最近压力趋势如何" → 不调用，本技能不产出趋势。
- 拿到读数后要出报告 → 读数本身仍是本技能，成文部分交 `inspection-report`。
